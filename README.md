# Excel Sales Data: Cleaning, Standardization & Visualization

## 📌 Project Overview
Is project mein maine raw sales data ko end-to-end clean, transform aur visualise kiya hai. Raw data mein kaafi inconsistencies aur missing values thi, jinhe Excel ke advanced functions aur tools ka use karke ek standard format mein laya gaya hai. Finally, business insights nikalne ke liye ek dynamic dashboard taiyar kiya gaya hai.

## 🛠️ Tools & Techniques Used
* **Data Cleaning:** Remove Duplicates, Text to Columns, Flash Fill, aur Handling Missing Values.
* **Data Transformation:** Data types ko standardise karna (Dates, Currency, and Regions).
* **Formulas & Functions:** `VLOOKUP` / `XLOOKUP`, `INDEX-MATCH`, `IFERROR`, `SUMIFS`, aur `COUNTIFS`.
* **Data Analysis & Visualization:** Pivot Tables, Pivot Charts, Slicers, aur Interactive Dashboards.

## 📊 Key Insights Delivered
* **Sales Performance:** Kis region aur kis time period (Month/Quarter) mein sabse zyada sales hui.
* **Top Products:** Kaun se products top-performing hain aur kaun se under-performing.
* **Customer Trends:** Repeat customers aur unka purchasing pattern.

## 📁 Repository Structure
* `data/`: Is folder mein raw aur cleaned data files hain.
* `dashboard/`: Final Excel workbook jisme interactive charts aur dashboard hain.
* `screenshots/`: Dashboard ki image previews.

## 🚀 How to Use this Project
1. Repository ko clone ya download karein.
2. `dashboard/` folder mein jaakar Excel file ko open karein.
3. Slicers ka use karke data ko filter karein aur dynamic insights dekhein.
